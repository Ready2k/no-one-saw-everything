# Audio Assets

Drop production audio files into the folders below using the filenames referenced in `manifest.json`.

## Folders

- `ambient/` - looping background beds
- `stingers/` - short dramatic event sounds
- `ui/` - small interface sounds

## Requirements

- Prefer `.mp3` for broad browser support.
- Ambient tracks should loop cleanly.
- Stingers should be short, usually 0.5s to 3s.
- Keep file sizes reasonable.
- Do not commit copyrighted audio unless licensed for use in the project.

## Manifest

All audio paths are configured in:

```txt
public/audio/manifest.json
```

Update the manifest when adding, renaming, or replacing audio files.
