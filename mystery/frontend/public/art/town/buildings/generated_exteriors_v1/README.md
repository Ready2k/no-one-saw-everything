# Generated Exteriors V1

Non-overwriting canonical exterior pass for the living town building set.

## Direction

- Match the existing production interiors in `frontend/public/art/town/buildings/production`.
- Keep the base buildings canonical and reusable across cases.
- Use neutral daylight base art; case time of day is handled by runtime tinting.
- Keep evidence, damage, fire, broken glass, and missing-object states as variants or overlays.
- Preserve the cosy storybook-medieval top-down/isometric RPG village style from the town art bible.
- Prefer the `_alpha.png` files for project use. Unsuffixed PNGs are preserved raw generated exports.
- `building_manifest_llm.json` points to the `_alpha.png` files and describes interior/exterior continuity for future story generation.
