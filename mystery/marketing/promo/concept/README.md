# Original-art concept campaign

This campaign intentionally imagines a more cinematic neo-noir visual direction
for *No One Saw Everything*. It does not reuse current gameplay captures.

| Master | Format | Creative premise |
| --- | --- | --- |
| `short-01-rewind.mp4` | 1080×1920 | The time-rewind mystery hook |
| `short-02-shadows.mp4` | 1080×1920 | The suspect psychology hook |
| `trailer-01-no-one-saw.mp4` | 1920×1080 | The premium umbrella campaign trailer |

Original generated key art is retained in `../original-art/`. The production
script is `scripts/promo/create_concept_teasers.sh`; it uses the generated art
plus existing project ambient tracks and creates only a disposable `.work/`
cache beside the masters.
